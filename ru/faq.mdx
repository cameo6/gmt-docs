## Покупка

<AccordionGroup>

<Accordion title="Как купить аккаунт?">
1. Откройте бота [@GetMyTGrobot](https://t.me/GetMyTGrobot)
2. Пополните баланс (Профиль → Пополнить баланс)
3. Выберите аккаунт из каталога
4. Оформите заказ
5. Перейдите по ссылке на сайт — там будет номер телефона

Подробнее — [Активация аккаунта](/ru/getting-started/first-steps).
</Accordion>

<Accordion title="Какие способы оплаты доступны?">
Доступные способы оплаты отображаются в боте: Профиль → Пополнить баланс.
</Accordion>

<Accordion title="Есть ли гарантия?">
Да. Если аккаунт не работает при первом входе — обратитесь в поддержку [@GetMyTGSUPbot](https://t.me/GetMyTGSUPbot).

Гарантия не распространяется на:
- Блокировки после успешного входа из-за ваших действий
- Проблемы из-за плохого IP или окружения
- Случаи, когда код был получен, но не введён вовремя
</Accordion>

<Accordion title="Можно ли вернуть аккаунт?">
Возврат возможен, если аккаунт не работает при первом входе. После успешного входа возврат невозможен.
</Accordion>

</AccordionGroup>

## Вход и активация

<AccordionGroup>

<Accordion title="Код не приходит, что делать?">
1. Убедитесь, что вы на экране ввода кода в Telegram
2. Нажмите «Получить код» на сайте (ссылка в боте)
3. Код появится на сайте — скопируйте и вставьте в Telegram

Если код не появляется — проблема может быть в IP или устройстве. Попробуйте сменить прокси или устройство.

Подробнее — [Решение проблем](/ru/issues/troubleshooting#проблемы-с-кодом).
</Accordion>

<Accordion title="Telegram требует Premium для входа">
Это значит, что ваш IP плохой (VPN, датацентр, в чёрных списках). Смените прокси на резидентный или мобильный.

Не покупайте Premium для обхода — это не решит проблему с IP.
</Accordion>

<Accordion title="Можно ли использовать VPN?">
Нет. IP популярных VPN известны Telegram и находятся в чёрных списках. Используйте качественные прокси.

Подробнее — [Почему не VPN](/ru/network/vpn).
</Accordion>

<Accordion title="Какой клиент Telegram использовать?">
Рекомендуем официальные клиенты:
- Telegram для iOS/Android
- Telegram Desktop
- Telegram Web

Неофициальные клиенты могут не получить код или вызвать подозрения.

Подробнее — [Поддерживаемые клиенты](/ru/getting-started/supported-clients).
</Accordion>

</AccordionGroup>

## После входа

<AccordionGroup>

<Accordion title="Что такое отлёжка?">
Период 3-5 дней после входа, когда нужно минимизировать активность. Telegram особенно внимательно следит за новыми сессиями.

В это время: читайте, отвечайте на входящие, не меняйте профиль и IP.

Подробнее — [Базовые концепции](/ru/getting-started/overview#отлёжка).
</Accordion>

<Accordion title="Нужно ли устанавливать 2FA?">
Да, обязательно. Это единственное, что нужно сделать сразу после входа.

Аккаунты зарегистрированы на виртуальные номера. Без 2FA кто-то может получить код и войти в ваш аккаунт.

Подробнее — [Безопасность](/ru/security/overview).
</Accordion>

<Accordion title="Получил спамблок сразу после входа">
Проблема с окружением:
- Плохой IP (VPN, датацентр)
- Несоответствие региона IP и номера
- Подозрительный Device ID

Смените прокси и попробуйте снова. Проверьте статус через @SpamBot.
</Accordion>

<Accordion title="Сколько аккаунтов можно на одном устройстве?">
Максимум 5, но чем меньше — тем лучше. Проблема с одним аккаунтом влияет на траст остальных.

Подробнее — [Окружение](/ru/accounts/env#device-id).
</Accordion>

</AccordionGroup>

## Технические вопросы

<AccordionGroup>

<Accordion title="Что такое Device ID?">
Уникальный идентификатор устройства. Telegram связывает аккаунты, которые входили с одного устройства.

Подробнее — [Окружение](/ru/accounts/env#device-id).
</Accordion>

<Accordion title="Что такое App ID и API Hash?">
Идентификаторы приложения для работы с Telegram API. Влияют на траст сессии.

Подробнее — [App ID и API Hash](/ru/accounts/app-id).
</Accordion>

<Accordion title="Какой прокси лучше?">
Резидентный или мобильный. Датацентровые и VPN не подходят.

Один прокси = один аккаунт. Не используйте один прокси для нескольких аккаунтов.

Подробнее — [Прокси](/ru/network/proxy).
</Accordion>

<Accordion title="Что такое FLOOD_WAIT?">
Ошибка «подожди X секунд». Появляется при слишком частых запросах. Подождите указанное время, повторные попытки увеличат задержку.
</Accordion>

</AccordionGroup>
