## Установка и обновление

### JavaScript и TypeScript

Используйте Node.js 20 или новее. Пакет включает типы TypeScript.

<CodeGroup>

```bash npm
npm install gmt-typescript-sdk@0.37.3
```

```bash yarn
yarn add gmt-typescript-sdk@0.37.3
```

```bash pnpm
pnpm add gmt-typescript-sdk@0.37.3
```

</CodeGroup>

### Python

Используйте Python 3.9 или новее.

```bash
python -m pip install "gmt-python-sdk==0.44.3"
```

При обновлении с JavaScript 0.37.0 или Python 0.44.0 названия пакетов и импорты клиентов остаются прежними.

## Первый запрос

Для проверки доступности API ключ не нужен. Для запросов с авторизацией задайте переменную окружения `GMT_API_KEY` с ключом из профиля бота. Клиенты прочитают её автоматически.

Чтобы запустить пример JavaScript в Node.js, сохраните его в файл `health-check.mjs` и выполните `node health-check.mjs`.

<CodeGroup>

```javascript JavaScript
import Gmt from 'gmt-typescript-sdk'

const client = new Gmt()
const result = await client.service.healthCheck()
console.log(result.status)
```

```python Python
from gmt import Gmt

with Gmt() as client:
    result = client.service.health_check()
    print(result.status)
```

```python Python (async)
import asyncio

from gmt import AsyncGmt


async def main():
    async with AsyncGmt() as client:
        result = await client.service.health_check()
        print(result.status)


asyncio.run(main())
```

</CodeGroup>

## Справочник API

На [странице проверки доступности](/sdk-reference/service/health-check) рядом с HTTP-методом приведены примеры для JavaScript и Python. Примеры для остальных операций есть во вкладке API. Для прямых запросов можно [скачать спецификацию OpenAPI](https://api.getmytg.com/docs/openapi.json).
