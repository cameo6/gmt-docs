## Установка и обновление

### JavaScript и TypeScript

Используйте Node.js 20 или новее. Пакет включает типы TypeScript.

<CodeGroup>

```bash npm
npm install gmt-typescript-sdk@0.37.5
```

```bash yarn
yarn add gmt-typescript-sdk@0.37.5
```

```bash pnpm
pnpm add gmt-typescript-sdk@0.37.5
```

</CodeGroup>

### Python

Используйте Python 3.9 или новее.

```bash
python -m pip install "gmt-python-sdk==0.44.6"
```

При обновлении с JavaScript 0.37.0 или Python 0.44.0 названия пакетов и импорты клиентов остаются прежними.

## Первый запрос

Для проверки доступности API ключ не нужен. Для запросов с авторизацией задайте переменную окружения `GMT_API_KEY` с ключом из профиля бота. Клиенты прочитают её автоматически.

Чтобы запустить пример JavaScript в Node.js, сохраните его в файл `health-check.mjs` и выполните `node health-check.mjs`.

<CodeGroup>

```javascript JavaScript
import Gmt from 'gmt-typescript-sdk'

const client = new Gmt()
const result = await client.service.healthCheck()
console.log(result.status)
```

```python Python
from gmt import Gmt

with Gmt() as client:
    result = client.service.health_check()
    print(result.status)
```

```python Python (async)
import asyncio

from gmt import AsyncGmt


async def main():
    async with AsyncGmt() as client:
        result = await client.service.health_check()
        print(result.status)


asyncio.run(main())
```

</CodeGroup>

### `accounts.list()` / `purchases.list()`

- Python · `client.accounts.list()` · `client.purchases.list()` · `client.purchases.list(include="code_request")`
- JavaScript / TypeScript · `await client.purchases.list({ sort: 'date_desc', include: 'code_request' })`

### `purchases.bulk.download()`

- Python · `client.purchases.bulk.download(purchase_id).write_to_file("accounts.zip")`
- Python (async) · `response = await client.purchases.bulk.download(purchase_id)` · `await response.write_to_file("accounts.zip")`
- JavaScript / TypeScript · `import { writeFile } from 'node:fs/promises'` · `const response = await client.purchases.bulk.download(purchaseId)` · `await writeFile('accounts.zip', Buffer.from(await response.arrayBuffer()))`
- HTTP 409 · `ConflictError`
