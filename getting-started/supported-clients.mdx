## Почему официальные клиенты

<AccordionGroup>

<Accordion title="Гарантированное получение кода">
Код подтверждения приходит через официальные серверы Telegram. Неофициальные клиенты могут не получить код или получить его с задержкой.
</Accordion>

<Accordion title="Корректный Device ID">
Официальные клиенты формируют Device ID стандартным способом. Это важно для траста сессии.
</Accordion>

<Accordion title="Актуальный App ID">
Встроенные App ID официальных клиентов имеют лучшую репутацию у Telegram.
</Accordion>

<Accordion title="Меньше подозрений">
Telegram знает паттерны поведения официальных клиентов. Отклонения от них вызывают подозрения.
</Accordion>

</AccordionGroup>

## Неофициальные клиенты

### Могут работать

Некоторые альтернативные клиенты основаны на официальном коде:

| Клиент | Платформа | Комментарий |
|--------|-----------|-------------|
| Telegram X | Android | Официальный альтернативный клиент |
| Nicegram | iOS | Популярный, но есть нюансы с трастом |
| Plus Messenger | Android | Форк официального клиента |

<Warning>
Даже если клиент работает, он может иметь худшую репутацию App ID или генерировать подозрительный fingerprint. Это повышает риск спамблока — особенно на новых аккаунтах или при активной работе.
</Warning>

### Не рекомендуются

| Клиент | Причина |
|--------|---------|
| Nekogram | Нестандартный fingerprint |
| BGram | Неизвестная репутация App ID |
| Сторонние веб-клиенты | Проблемы с получением кода |

## Библиотеки для автоматизации

Если вы используете аккаунт для автоматизации:

| Библиотека | Язык | Статус |
|------------|------|--------|
| Telethon | Python | Работает, но встроенный App ID имеет худшую репутацию |
| Pyrogram | Python | Работает, аналогично Telethon |
| TDLib | C++/любой | Требует свой App ID |
| GramJS | JavaScript | Работает для веб-приложений |

<Note>
Для автоматизации рекомендуем использовать App ID из официальных клиентов вместо встроенных в библиотеки. Подробнее — [App ID и API Hash](/accounts/app-id).
</Note>

## Процесс входа

Независимо от клиента, процесс одинаковый:

1. Откройте клиент Telegram
2. Введите номер телефона из бота
3. Дождитесь экрана ввода кода
4. Нажмите «Получить код» на сайте (ссылка в боте)
5. Введите код в клиент
6. Если есть 2FA — введите пароль (тоже на сайте)

<Warning>
Код выдаётся один раз. Если закрыли Telegram до ввода кода — он сгорает.
</Warning>

## Проблемы с клиентами

| Проблема | Решение |
|----------|---------|
| Код не приходит | Попробуйте официальный клиент |
| Требует Premium | Проблема с IP, не с клиентом |
| Сессия сразу сбрасывается | Проверьте стабильность прокси |
| Ошибка при входе | Попробуйте другое устройство |
