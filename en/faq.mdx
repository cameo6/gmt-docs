## Login and Activation

<AccordionGroup>

<Accordion title="The code isn't arriving, what should I do?">
1. Make sure you're on the code entry screen in Telegram
2. Click "Get Code" on the website (link in the bot)
3. The code will appear on the website — copy and paste it into Telegram

If the code doesn't appear — the problem might be with the IP or device. Try changing the proxy or device.

More details — [Troubleshooting](/en/issues/troubleshooting#code-issues).
</Accordion>

<Accordion title="Telegram requires Premium to log in">
This means your IP is bad (VPN, datacenter, blacklisted). Switch to a residential or mobile proxy.

Don't buy Premium to bypass this — it won't solve the IP problem.
</Accordion>

<Accordion title="Can I use a VPN?">
No. IPs of popular VPNs are known to Telegram and are blacklisted. Use quality proxies instead.

More details — [Why Not VPN](/en/network/vpn).
</Accordion>

<Accordion title="Which Telegram client should I use?">
We recommend official clients:
- Telegram for iOS/Android
- Telegram Desktop
- Telegram Web

Unofficial clients may not receive the code or raise suspicion.

More details — [Supported Clients](/en/getting-started/supported-clients).
</Accordion>

</AccordionGroup>

## After Login

<AccordionGroup>

<Accordion title="What is the warm-up period?">
A 3-5 day period after login when you need to minimize activity. Telegram pays extra attention to new sessions.

During this time: read, reply to incoming messages, don't change your profile or IP.

More details — [Basic Concepts](/en/getting-started/overview#warm-up-period).
</Accordion>

<Accordion title="Do I need to set up 2FA?">
Yes, absolutely. This is the only thing you need to do right after login.

Accounts are registered to virtual numbers. Without 2FA, someone could get the code and log into your account.

More details — [Security](/en/security/overview).
</Accordion>

<Accordion title="Got a spamblock right after login">
Environment issue:
- Bad IP (VPN, datacenter)
- Region mismatch between IP and phone number
- Suspicious Device ID

Change your proxy and try again. Check status via @SpamBot.
</Accordion>

<Accordion title="How many accounts can I have on one device?">
Maximum 5, but fewer is better. A problem with one account affects the trust of others.

More details — [Environment](/en/accounts/env#device-id).
</Accordion>

</AccordionGroup>

## Technical Questions

<AccordionGroup>

<Accordion title="What is Device ID?">
A unique device identifier. Telegram links accounts that logged in from the same device.

More details — [Environment](/en/accounts/env#device-id).
</Accordion>

<Accordion title="What are App ID and API Hash?">
Application identifiers for working with Telegram API. They affect session trust.

More details — [App ID and API Hash](/en/accounts/app-id).
</Accordion>

<Accordion title="Which proxy is best?">
Residential or mobile. Datacenter and VPN don't work.

One proxy = one account. Don't use one proxy for multiple accounts.

More details — [Proxy](/en/network/proxy).
</Accordion>

<Accordion title="What is FLOOD_WAIT?">
An error meaning "wait X seconds". Appears when making too many requests. Wait the specified time — repeated attempts will increase the delay.
</Accordion>

</AccordionGroup>
