## After Purchase

You've paid for an account and received a link to a website with the phone number. Now you need to log into Telegram.

<Steps>
<Step title="Connect the Right IP">
Before logging in, make sure your IP matches the account's region. Use a proxy if needed.
</Step>

<Step title="Open Telegram">
Launch the official Telegram client on your phone or computer. Unofficial clients may not receive the code.
</Step>

<Step title="Enter the Number">
Enter the phone number you received after purchase. Telegram will send a code.
</Step>

<Step title="Get the Code">
Follow the link in the bot to the website and click "Get Code". The code will appear there.
</Step>

<Step title="Enter the Code in Telegram">
Copy the code from the website and paste it into Telegram.
</Step>

<Step title="Enter 2FA (if enabled)">
If two-factor authentication is enabled on the account, the password will also be on the website.
</Step>
</Steps>

## Code Not Arriving?

<Note>
Sometimes Telegram sends the code to email instead of SMS. This is normal. Click "Get Code" on the website — the system will automatically retrieve the code from email.
</Note>

If the code still doesn't appear or you have other issues — see [Troubleshooting](/en/issues/troubleshooting#code-issues).

## After Login

You're in. Now the account needs a [warm-up period](/en/getting-started/overview#warm-up-period) — 3-5 days of minimal activity.

<Note>
**The only exception:** set up 2FA immediately after login. This will protect the account from hijacking.
</Note>

During the warm-up period:
- Use minimally: read, reply to incoming messages
- Don't change profile, IP, don't join groups

After 3-5 days, you can fill out your profile and increase activity.

<Warning>
If you get a spamblock right after login, it signals environment problems: bad IP, suspicious Device ID, or region mismatch.
</Warning>
