## Install or upgrade

### JavaScript and TypeScript

Use Node.js 20 or later. The package includes TypeScript declarations.

<CodeGroup>

```bash npm
npm install gmt-typescript-sdk@0.37.3
```

```bash yarn
yarn add gmt-typescript-sdk@0.37.3
```

```bash pnpm
pnpm add gmt-typescript-sdk@0.37.3
```

</CodeGroup>

### Python

Use Python 3.9 or later.

```bash
python -m pip install "gmt-python-sdk==0.44.3"
```

The package names and client imports stay the same when upgrading from JavaScript 0.37.0 or Python 0.44.0.

## Make your first request

The health check works without an API key. For authenticated operations, set the `GMT_API_KEY` environment variable to the key from your bot profile. The clients read it automatically.

To run the JavaScript example in Node.js, save it as `health-check.mjs` and run `node health-check.mjs`.

<CodeGroup>

```javascript JavaScript
import Gmt from 'gmt-typescript-sdk'

const client = new Gmt()
const result = await client.service.healthCheck()
console.log(result.status)
```

```python Python
from gmt import Gmt

with Gmt() as client:
    result = client.service.health_check()
    print(result.status)
```

```python Python (async)
import asyncio

from gmt import AsyncGmt


async def main():
    async with AsyncGmt() as client:
        result = await client.service.health_check()
        print(result.status)


asyncio.run(main())
```

</CodeGroup>

## API reference

Open the [health check reference](/sdk-reference/service/health-check) to see the JavaScript and Python SDK examples next to the HTTP endpoint. The API tab includes the same examples for the other operations. You can also [download the OpenAPI specification](https://api.getmytg.com/docs/openapi.json) to make requests directly.
